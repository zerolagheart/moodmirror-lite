# 🪞 MoodMirror Lite — Neon Glass Edition

MoodMirror Lite is a dark aesthetic mood journaling and analytics web app built with **Python, Streamlit, Pandas and Plotly**.  
It allows users to log their daily mood, track energy levels, write reflections, explore mood patterns over time, and export their data — all inside a polished neon glass UI.

---

## ✨ Features

### 🌙 Mood Logging
- Log daily mood entries
- Track energy levels on a scale of 1–10
- Write short reflections or journal notes
- Save all entries locally in CSV format

### 📔 Mood Journal
- View past entries in a journal-style layout
- Filter by:
  - mood
  - minimum energy
  - date range
- Delete unwanted entries directly from the app

### 📊 Insights & Analytics
- Mood frequency bar chart
- Mood distribution donut chart
- Energy trend over time
- Mood score trend visualization
- Weekly summary insights
- Best energy day detection
- Current logging streak

### 💾 Export
- Download mood data as a CSV file directly from the app

### 🎨 UI / Experience
- Dark neon glassmorphism-inspired interface
- Custom CSS styling
- Dashboard layout with stat cards and reflection cards
- Designed as a polished mini HCI / UIUX product prototype
